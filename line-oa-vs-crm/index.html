LINE 官方帳號和 LINE CRM 差在哪？什麼時候需要 CRM

作者：明哲 MOMO（mecango LINE 會員裂變導入顧問）｜最後更新：2026-11-25

重點先講LINE 官方帳號是「和好友溝通」的工具：群發、聊天、圖文選單與基本分眾。LINE CRM 是接在官方帳號上的「會員系統」：記錄每位會員實際花了多少錢、來了幾次、是誰推薦的，再依這些資料自動分級、發獎勵、串接 POS 與預約。只想通知活動，官方帳號就夠；想知道誰是熟客、讓熟客回來、讓熟客帶新客，就需要 CRM。

先看 LINE 官方帳號本身能做什麼

LINE 官方帳號可以免費申請，後台內建歡迎訊息、圖文選單、群發推播、一對一聊天，以及優惠券、集點卡等基本工具。中用量以上的方案還能使用「官方帳號分眾+」，不需要串接 API 就能用訊息標籤把好友分類。

費用主要看訊息量：輕用量、中用量、高用量方案每月分別有 200、3,000、6,000 則免費訊息，超過要加購；一對一手動聊天不計入。實際價格以 LINE 官方公告為準。

截至 2026 年 10 月，台灣已有超過 360 萬個 LINE 官方帳號，而且 86% 的 LINE 使用者曾使用官方帳號。帳號越多，只靠群發越難被看見，這也是越來越多店家開始經營會員的原因。

三個訊號：你該導入 CRM 了

1. 群發越來越貴，效果越來越差

每次都發給所有好友，訊息費一直增加，封鎖數也跟著上升。CRM 讓你只發給對的人。

2. 說不出誰是你的前 20% 熟客

官方帳號看得到誰點了訊息，但看不到誰在店裡花最多錢。沒有消費資料，就很難做會員分級與回購經營。

3. 想讓熟客帶朋友來，卻沒辦法追蹤

「推薦朋友有獎勵」最大的問題是記錄誰推薦了誰。CRM 會在朋友透過分享連結加入時自動綁定推薦人，到店消費後自動發獎勵，這就是會員裂變。

常見問題

導入 CRM 要換掉原本的 LINE 官方帳號嗎？

不用。CRM 透過 LINE 的 Messaging API 串接你原本的官方帳號，好友、帳號名稱與 ID 都不變。

用了 CRM，LINE 的訊息費還要付嗎？

要。群發與系統推播的訊息仍依 LINE 官方帳號方案計費，CRM 的費用是另外的系統費。分眾推播能減少不必要的群發，會員分享則能降低對大量推播的依賴。

不確定你的店需不需要 CRM？

加 LINE 告訴我你的產業和目前好友數，我幫你判斷官方帳號夠不夠用。透過這個按鈕加入，你也能親自體驗推薦綁定是怎麼運作的。
